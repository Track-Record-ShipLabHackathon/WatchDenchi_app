# 学習データについて

2026-11-19にメーカー公式ページ・取扱説明書で確認した仕様上の寿命15件です。
各行の`source_url`に日数と条件の出典を記録し、電池サイズ・本数の確認先を`battery_source_url`に記録しました。
サイズや色の違いを別サンプルとして増やしていません。人工的な交換日・架空の実測データは作成していません。

## 採用した条件

- 対象は乾電池を使うマウス。
- 新品のアルカリ電池を使用。
- 1日8時間のPC利用のうち5%をマウス操作に割り当てるという公表条件。
- ラベルは公表された使用可能日数。最大値は`published_maximum`、目安は`published_reference`として区別して記録。
- 月・年・連続動作時間しかない資料は今回の学習から除外し、換算による条件差を避けた。

## 解釈上の限界

公表最大値と参考値は定義が完全には一致しません。同じ「8時間の5%」でも、スリープ・非使用時の電源操作・無線方式などは製品ごとに異なります。
単3の資料はBUFFALO、単4の資料はELECOMに偏っているため、電池サイズによる差とマウスメーカーによる差を切り分けられません。
したがって、このデータは入力を最小限にした学習デモ用であり、市場全体の統計や実際の交換時期を代表していません。

`mouse_manufacturer`はマウスの製造元です。ユーザー入力の`manufacturer`は電池の製造元であり、両者は別の情報です。
資料では電池製造元が不明なので、CSVの`battery_manufacturer`は全行`unknown`です。これをマウスメーカーで埋めて学習することは禁止します。

## 学習・評価での扱い

`type`と`battery_quantity`を特徴量、`service_days`を正解値として回帰木を学習します。
`started_at`は学習させず、推論した日数を加えるために使います。装着日の新旧によって新品からの寿命が変わるという誤った関係を学習させません。
`chemical`はアルカリの資料しかないため対応条件の確認に使い、`manufacturer`には根拠のない補正を掛けません。

評価では製品系列を丸ごと学習から外します。BUFFALOの500系同士と115系同士はそれぞれ同じグループとして扱い、近縁製品が学習側と評価側に分かれにくくしています。
15製品・13グループでの評価結果を`../model/evaluation.json`に保存します。実際の利用者の交換日での評価ではありません。
